# 深度图+彩色图联合矩形检测 技术文档

## 概述

在 `det-src/det-rect.cpp` 中实现了基于深度图和彩色图联合的矩形物体检测算法。核心策略是**深度优先、颜色回退**：先尝试深度分割，失败时自动切换到 HSV 颜色分割。支持利用已知物理尺寸进行 3D 平面拟合精化。

## 算法流程

```
彩色图(.jpg) + 深度图(.png, 16-bit, mm)
        │
        ▼
┌─────────────────────────────┐
│ 1. 估计目标深度               │  中心区域采样深度值，取中位数
│    estimateTargetDepth()     │
└──────────────┬──────────────┘
               ▼
┌─────────────────────────────┐
│ 2. 深度分割 (主路径)           │  百分比容差: tol = max(50mm, center×15%)
│    createDepthMask()        │  区间 [center-tol, center+tol]
│                             │  形态学去噪 → findContours
│                             │  边界触碰过多时自动收紧重试 (max 3次)
└──────────────┬──────────────┘
               ▼
┌─────────────────────────────┐
│ 3. 深度结果质量判断            │  bbox覆盖率>75%? 边界触碰≥3?
│                             │  像素尺寸偏离期望>40%? (有phys尺寸时)
│    ✓ 有效 ──→ 步骤4          │
│    ✗ 无效 ──→ 颜色备选        │
└──────────┬───────┬──────────┘
           │       ▼
           │  ┌─────────────────────────────┐
           │  │ 3b. 颜色分割 (备选路径)        │  HSV 蓝色筛选 H:[90,140]
           │  │     detectByColor()         │  形态学闭运算填充网格间隙
           │  │                             │  最大轮廓 → 四边形拟合
           │  └──────────────┬──────────────┘
           │                 │
           ▼                 ▼
┌─────────────────────────────┐
│ 4. 四边形拟合                 │  凸包 → approxPolyDP(多epsilon搜索)
│    fitQuad()                │  → minAreaRect 兜底
└──────────────┬──────────────┘
               ▼
┌─────────────────────────────┐
│ 5. 角点排序                   │  按 y 排序 → 分上下两组 → TL,TR,BR,BL
│    orderCorners()           │
└──────────────┬──────────────┘
               ▼
┌─────────────────────────────┐
│ 6. 深度梯度精化 (仅深度路径)    │  在角点 15×15 邻域搜梯度最大值
│    refineCornersWithDepthGradient()
└──────────────┬──────────────┘
               ▼
┌─────────────────────────────┐
│ 7. 彩色图亚像素精化            │  cv::cornerSubPix (灰度图)
│                             │
└──────────────┬──────────────┘
               ▼
┌─────────────────────────────┐
│ 8. 已知物理尺寸 3D 精化(可选)  │  见下方详解
│    refineWithKnownSize()    │
└──────────────┬──────────────┘
               ▼
         输出 4 个角点 + JSON
```

## 核心数据结构

```cpp
struct CenterRectConfig {
    // --- 深度分割参数 ---
    double depth_tolerance_ratio = 0.15;  // 深度容差比例：tol = max(50, center_depth * ratio)
    double center_ratio = 0.15;           // 中心采样区域占图像短边的比例
    double approx_eps = 0.02;             // 多边形逼近精度系数
    double min_area_ratio = 0.02;         // 最小面积占图像面积比例

    // --- 已知物理尺寸精化（设 <=0 则跳过），默认关闭 ---
    double phys_width_mm = 0;
    double phys_height_mm = 0;

    // --- 相机内参 ---
    double cam_fx = 611.017;
    double cam_fy = 611.182;
    double cam_cx = 638.487;
    double cam_cy = 404.831;

    // --- 颜色备选检测（深度分割失败时回退） ---
    bool use_color_fallback = true;       // 是否启用颜色回退
    int color_h_low = 90;                 // HSV 色相下限 (蓝色 ~90-140)
    int color_h_high = 140;              // HSV 色相上限
    int color_s_min = 50;                // 饱和度下限
    int color_v_min = 50;                // 明度下限
};
```

相机内参来自 `build/param/camera_params.yaml`。

## 颜色备选检测 (detectByColor)

当深度分割因目标与背景深度重叠而失效时，自动回退到 HSV 颜色分割。

### 触发条件

以下任一条件满足时，判定深度分割无效：

| 条件 | 说明 |
|------|------|
| bbox 覆盖率 > 75% | 轮廓包围盒超过图像面积的 75%，mask 已泄漏到全图 |
| 边界触碰 ≥ 3 边 | 轮廓紧贴图像边界 |
| 像素尺寸偏差 > 40% | 指定了 phys 尺寸时，检测到的像素尺寸与期望值偏差过大 |

### 颜色分割流程

1. **HSV 颜色筛选**: `cv::inRange(hsv, Scalar(90,50,50), Scalar(140,255,255))`
2. **形态学处理**: 闭运算(5×5椭圆核) 填充物体内部网格间隙，开运算(3×3矩形核) 去噪
3. **轮廓筛选**: 找面积最大的、包含图像中心或面积足够大的轮廓
4. **四边形拟合**: 复用 `fitQuad()` → `orderCorners()`
5. **亚像素精化**: `cv::cornerSubPix`
6. **3D 精化**: 走相同的 `refineWithKnownSize()` 流程

## 已知尺寸 3D 精化算法详解

利用已知的物理尺寸和相机内参，通过 3D 平面拟合迭代调整角点位置。

### 步骤

```
                    TL(0) ──── Top ──── TR(1)
                     │                    │
                    Left                Right
                     │                    │
                    BL(3) ─── Bottom ─── BR(2)
```

**1. 矩形内部 3D 点采样**
- 将矩形收缩 20%（避免边缘混合像素）
- 在收缩后的多边形内，用深度值将像素转为 3D 点：
  ```
  X = (u - cx) × Z / fx
  Y = (v - cy) × Z / fy
  Z = depth_mm
  ```

**2. PCA 平面拟合**
- 对内部 3D 点做 PCA
- 最小特征值对应的特征向量 = 平面法线 n
- 确保法线指向相机（z > 0）

**3. 建立像素→平面深度映射**
- 射线与平面的交点公式：
  ```
  Z = -d / (n₀×(u-cx)/fx + n₁×(v-cy)/fy + n₂)
  ```

**4. 计算 3D 边长度**
- `edgePair3DDistance(边1端点, 边2端点, N=20)`：
  沿两条平行边各采样 N+1 个点，用平面方程算 Z，转 3D 坐标，求对应点对的距离均值
- 宽度 = 左边(TL→BL) 与 右边(TR→BR) 的 3D 距离
- 高度 = 上边(TL→TR) 与 下边(BL→BR) 的 3D 距离

**5. 迭代调整**
```
for iter in 0..9:
    w_3d = 当前 3D 宽度
    h_3d = 当前 3D 高度

    w_err = w_3d - physWidth    // 正=太宽需收缩
    h_err = h_3d - physHeight

    if |w_err| < 0.3mm and |h_err| < 0.3mm: 收敛，退出

    mmPerPx = avgZ / fx          // 像素→毫米缩放因子
    dw_px = -w_err / (2×mmPerPx) // 每边移动像素量
    dh_px = -h_err / (2×mmPerPx)
    clamp(dw_px, dh_px, ±20px)   // 限幅防发散

    // 移动四条边（每条边沿外法线方向）
    n_top   = outwardNormal(TL, TR)   // 指向矩形外
    n_right = outwardNormal(TR, BR)
    n_bot   = outwardNormal(BR, BL)
    n_left  = outwardNormal(BL, TL)

    TL += n_left×dw_px  + n_top×dh_px
    TR += n_right×dw_px + n_top×dh_px
    BR += n_right×dw_px + n_bot×dh_px
    BL += n_left×dw_px  + n_bot×dh_px
```

**6. 输出**: `cv::Point2f` 四舍五入为 `cv::Point`，clamp 到图像范围内。

## 命令行接口

```bash
# 基本检测（不使用已知尺寸精化，仅深度分割）
./det-tool-lib <图像目录> rect <输出目录> <序号>

# 带已知物理尺寸精化（深度分割 + 3D 精化，失败时自动回退颜色）
./det-tool-lib <图像目录> rect <输出目录> <序号> <物理宽mm> <物理高mm>

# 批量检测目录下所有 .jpg 文件
./det-tool-lib <图像目录> rect <输出目录> [物理宽mm] [物理高mm]
```

```bash
# 蓝色网格矩形 (1000×1000mm)

./det-tool-lib build/tray_img/test rect "" 00002 1195 600
```

## 关键设计决策

| 决策 | 原因 |
|------|------|
| 深度优先 + 颜色回退 | 深度是物体边界的本质特征，优先使用；颜色在深度失效时提供可靠备选 |
| 百分比深度容差 (15%) | 自适应不同距离：近处物体 ±50mm 够用，远处物体 15% 能覆盖透视深度变化 |
| 边界触碰重试 (max 3次) | mask 泄漏到背景时自动收紧容差，避免把整张图当目标 |
| 期望尺寸验证 (>40% 偏差触发回退) | 指定物理尺寸时，快速判断深度检测是否找错了物体 |
| 颜色 HSV 范围内置蓝色 | 当前应用场景均为蓝色目标物，如需其他颜色修改 config 即可 |
| 平面拟合用 PCA 而非 RANSAC | 内部点已经是有效深度点（已过滤），PCA 更快且等价 |
| 每次迭代限幅 ±20px | 防止平面拟合误差导致边移动过度发散 |
| 物理尺寸默认 0 禁用 | 不同场景物体尺寸不同，默认不精化更安全 |
| 浮点角点 → 整数输出 | 调用方通常需要像素坐标，亚像素精度在 3D 精化阶段已体现 |
